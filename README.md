# 分数ラボ

5年生・算数「分数のたし算・ひき算」の学習アプリ。単一HTML（index.html）で動作し、データは端末内（localStorage）にだけ保存します。

※ アプリ名「分数ラボ」は仮称です（子どもの画面には仮称の注記は出しません）。

## 概要

主役は分数バー（テープ図）。全体の長さは常に「1」で、区画数＝分母、色のついた区画数＝分子になるよう、HTML/CSSで数学的に正確に動的生成します。「分母をそろえる（通分）」とは「1つ分の大きさをそろえる」ことだと、図の変化で分かることをねらいにしています。

### 5つのモード

| モード | 内容 | 案内キャラ |
|---|---|---|
| MODE1 分数を見てみよう | 探索型。分母・分子をステッパーで変えて2本のバーを比べる。お題（ミッション）5つ | つき |
| MODE2 通分マスター | 確認→そろえる分母を選ぶ→何倍か→分子を何倍か→結果確認の5ステップ | かい |
| MODE3 たし算トレーニング | 6段階（同分母→倍数関係→最小公倍数→通分後の分子計算→約分→図なし総合）。ロックなし | りく |
| MODE4 ひき算トレーニング | 同上。バーでは取り除く区画を斜線で示す | なみ |
| MODE5 まとめチャレンジ | 通分3問＋計算7問。始める前に図の表示（大きく／小さく／なし）を選べる | さく |

トップと学習の記録の案内は そら。

### 学習の流れ（TT-sensei標準）

- 練習：ステップごとにその場で支援が出る（1回目の間違い＝短いヒント、2回目＝図を使った説明、3回目＝答えを見せて「分かった、次へ進む」）。
- 間違い記録：最初に間違えた段階（そろえる分母／何倍／通分後の分子／分子の計算／約分）つきで端末内に記録。
- 特訓（とっくん）：記録された問題そのものを再出題し、全行程を正しく解けたら記録が消える。
- 学習の記録：「できるようになったこと」チェックリスト、モード別の記録、間違えた問題の一覧が見られる。
- フィードバックは長い解説ではなく、隣に座る先生のような短い問いかけと認める言葉を基本にしています。

### 通分アニメーション

通分後の分子を入れるステップで自動再生（「図の変化をもう一度見る」ボタンで再演可）。各区画が破線でさらに等分され、「色の区画 n個 → n×k個」のキャプションと ×k バッジで、大きさは変わらず数え方だけが細かくなることを見せます。

## 設計判断

- テーマ色：オレンジ〜amber系（#dd7f1e）。分数バーの青（#2e7cc2）と競合しないよう、UI側は暖色に寄せました。背景は明るいクリーム色、白い角丸カード、ダーク配色なし。
- トップ画面の場面絵：NAVI CHARACTER の学習場面絵（原本PNG）3枚からランダム表示（group-learning-math-diagram / trio-learning-graph-kai-tsuki-nami / trio-learning-discussion-riku-saku-kai）。6人集合絵は使っていません。
- 問題生成の条件：
  - 分母は2〜12、入力する分数は既約な真分数のみ。
  - 通分後の分母（最小公倍数）は36以下になる組み合わせだけを出す。
  - たし算の答えは1以下（帯分数は初期版の対象外）、ひき算は負にならない（答えが0になる問題も出さない）。
  - 段階1〜3・6の答えは約分が要らない形にそろえ、段階5では約分が必要な答えを意図的に出す。
  - 1セット10問は重複なし（問題キーで dedup）。
- 入力方法：途中式を入力する方式が基本。段階えらび画面で「答えだけ入力」に切り替え可能（設定として端末保存）。答えだけ入力でも、約分していない答えは「約分」段階のつまずきとして扱います。
- 図の表示：大きく／小さく／なし を設定（トップ）と解く画面の両方で切り替え可能。図なしのときは「図を見る」ボタンで一時的に表示できます。段階6は図なしで始まります。
- 仕様から判断して決めた点：
  - MODE1は探索型のため、間違い記録の対象にしていません（お題の達成だけを記録）。
  - 3回目の間違いでは答えを見せて次へ進む方式にしました（行き詰まって止まらないため）。記録は残るので特訓で克服できます。
  - 帯分数・答えが1を超えるたし算は初期版の対象外（仕様どおり）。
- 外部読み込み：自前サイトの共通基盤だけです（edu-effects、sounds-recipe-、navi-character の画像）。外部API・外部CDN・外部フォントは不使用。オフラインでも（共通基盤のキャッシュ範囲で）基本機能が動作します。

## 保存キー（localStorage）

- `fractionLab.mistakes.v1`：間違えた問題と、最初に間違えた段階
- `fractionLab.stats.v1`：モード別の解いた数・1回で正解した数、お題の達成、約分・図なし・特訓克服の累計
- `fractionLab.settings.v1`：音 ON/OFF、図の大きさ、入力方法（途中式／答えだけ）

## 検証

- エンジン自動テスト：仕様§15の確認テスト8問が全て正答になることを確認。24,000問の大量生成で不変条件（区画数＝分母、通分前後で大きさ不変、最小公倍数の正しさ、約分の正しさ、ひき算で負にならない、通分後の分母≤36、たし算の答え≤1）を全件確認。
- Playwright実走テスト（1180×820、共通基盤はローカルミラー経由）：31項目全合格。全モードを最後まで解けること、間違い記録（段階つき）と特訓での克服、設定の保存、解く画面のスクロールなし（最大 scrollHeight 820）、ページエラーなし。
- テストスクリプトは `test_app.py`、スクリーンショットは `shots/` にあります。
